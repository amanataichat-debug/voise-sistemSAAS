# Подключение нового клиента за 30 минут (без программиста)

Для владельца платформы. Всё делается в кабинете; код, Render и сервер не трогаем.
Принцип: платформа уже умеет вести переписку, звонить, писать в CRM и соблюдать лимиты. От вас —
персона, продукт, сценарий и факты. Каждый факт пишется в одном месте.

| Что | Где живёт | Кто читает |
|---|---|---|
| Персона и сценарий продаж (переписка) | Инструкции → «Для переписки» | агент в мессенджерах, разбор звонков |
| Персона и сценарий звонка | Инструкции → «Для звонков» | голос на звонке (все движки) |
| Цены, тарифы, условия, ответы на частые вопросы, каталог, файлы | «Знания агента» (база знаний) | переписка и звонок |
| Сайт и номер для звонка | Настройки → «Фирменный стиль» → «Контакты компании» | переписка, звонок, PDF-документы |

---

## 0. Перед началом (2 мин)
- Клиент оплатил тариф: Старт (переписка + CRM) или Profi (ещё и звонки агента).
- У клиента под рукой: телефон с WhatsApp, личный Telegram (если нужен), доступ к Instagram-аккаунту,
  прайс и 5–10 частых вопросов клиентов.

## 1. Агент (3 мин)
1. Кабинет клиента → Старт: «Чат-бот» → «Создать бота»; Profi: «Агент обзвона» → мастер создания.
2. Имя агента — как будет представляться клиентам (Айгерим, Анри…).
3. Модель бота оставьте по умолчанию.

## 2. Инструкции (7 мин)
Возьмите шаблоны и замените данные Voksy на данные клиента:
- `docs/orchestrator_prompt_anri.md` → «Инструкции» → «Для переписки».
- `docs/voice_agent_prompt_anri.md` → «Инструкции» → «Для звонков».

Пишите только: кто агент, что продаёт компания, как вести клиента по шагам, чего не делать. **Не пишите**
цены, правила формата, языка и CRM — их держит платформа (повтор только путает модель).
Персонаж мужской — выберите мужской голос, женский — женский.

## 3. База знаний (10 мин) — «Знания агента»
1. **Вопрос — ответ:** 5–15 частых вопросов («Сколько стоит?», «Где вы находитесь?», «Есть доставка?»).
   Ответ — как сказал бы сотрудник, 1–2 предложения.
2. **О компании:** короткие разделы — что делаем, график, адрес, условия оплаты.
3. **Каталог:** услуги/товары с ценой; к позиции можно добавить фото.
4. **Файлы:** прайс PDF, презентация. У файла два переключателя: «агент отправляет клиентам» и
   «агент ищет ответы внутри».
5. Нажмите «Спросить как клиент» и задайте 3–4 вопроса — ответы должны быть из базы.
6. Цены пишите один раз, только здесь.

## 4. Контакты компании (1 мин)
Настройки → «Фирменный стиль» → «Контакты компании»: `сайт · телефон` (например
`aigerim.kg · +996 700 123 456`). Агент даёт их клиенту, когда уместно, и ставит в PDF-документы.

## 5. Каналы (5 мин)
- **WhatsApp:** «Каналы» → WhatsApp → QR → сканировать с телефона клиента. «Кому отвечать»: «Всем, кто
  написал» — для заявок из рекламы; «Только клиентам из CRM» — если на номер пишут друзья и родные.
- **Telegram (личный):** номер → код → пароль 2FA (если есть).
- **Instagram:** подключить бизнес-аккаунт. Отвечать можно только в течение 24 часов после сообщения клиента.
- **Оповещения владельцу:** «Подключить мой Telegram» — придут новые клиенты, итоги звонков, сводка за день,
  предупреждение, если кончились кредиты.

## 6. Голос и телефония (только если нужны звонки, 2 мин)
1. «Модель голоса»: **Voksy Live** (GPT-Live) — самый живой разговор; **Voksy Voice** — лучший кыргызский
   голос (синтез ElevenLabs). Если клиенты в основном говорят по-кыргызски — сравните оба тест-звонком.
2. Голос — под персонажа (мужской/женский).
3. «Телефония» → номер → привязать к агенту. Звонить агент может только на номера O! (050, 070).
4. Первая фраза входящего звонка — короткая: «Здравствуйте! Это Айгерим, салон «…». Чем могу помочь?»

## 7. Проверка (до 5 мин)
1. Напишите в WhatsApp клиента с другого номера: «Сколько стоит?» — ответ за ~20 секунд, 1–3 строки,
   цена из базы.
2. Напишите «давайте созвонимся» — Profi с номером O!: агент звонит сам; иначе даёт номер и шлёт вам
   оповещение.
3. Позвоните на номер агента: по-русски, потом скажите «кыргызча сүйлөшөлүчү».
4. Откройте «Диалоги» → звонок → «Логи звонка» и CRM → карточку: имя, итог, факты записаны.

## Если что-то не так
| Симптом | Где смотреть |
|---|---|
| Агент не ответил в мессенджере | Канал подключён? «Кому отвечать»? Бот не на паузе (владелец писал сам — пауза 30 мин)? Кредиты? |
| Агент выдумывает цену | Нет вопроса в базе знаний → добавьте; раздел «Чего не хватает» показывает вопросы без ответа |
| Говорит длинно / не тем тоном | Уберите из инструкций правила формата, оставьте персону и сценарий |
| Плохой кыргызский на звонке | Сравните Voksy Voice и Voksy Live тест-звонком |
| SMS | Не работают: у платформы нет SMS-провайдера |
