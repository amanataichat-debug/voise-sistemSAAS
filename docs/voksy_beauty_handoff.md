### Не проверено на живых данных (проверить при первой возможности)

1. Чат на сайте с **настоящим ботом и кредитами** (в тестах ответ бота подставлен заглушкой).
2. Push-уведомления на **реальном телефоне** (Android — в браузере; iPhone — только у установленного приложения).
   Ключи VAPID: лучше задать в Render `VAPID_PRIVATE_KEY` / `VAPID_PUBLIC_KEY`, иначе создаются в базе сами.
3. Сценарии ИИ-управляющего на **живых клиентах** (письма и звонки в 10:00–20:00, режим «на одобрение»).
4. Задеплоена ли ветка `2511-beauty` на Render — уточнить (Render деплоит ту ветку, к которой привязан).

5. Главная салона и журнал на **живом салоне**: «Предложить клиентам» (подбор давних клиентов мастера), загрузка
   мастеров при сменах 2/2 (сейчас график — по дням недели), «сообщения без ответа» при большом инбоксе.
6. Приложение не стартует локально через `uvicorn app:app` на пустой базе: alembic «Multiple head revisions»
   (не связано с Beauty; на Render старт идёт своей веткой). Для снимков запускали приложение без startup-хуков.

### Отложено (не забыть)

- Режим «на одобрение» для существующих касаний воронки у **Profi других ниш** (сейчас настройка
  автономности действует только на сценарии салона) — отдельная задача.

## 2а. Следующий шаг — этап 2 «Клиенты возвращаются»

Предлагаемый порядок (согласовать с владельцем): карточка клиента beauty (ДР, любимые мастер и услуга, сумма, неявки,
источник) → отзывы и рейтинг на странице салона → лист ожидания → кабинет клиента «Мои записи» → голос: перенос и
отмена, звонок-подтверждение. Вопросы владельцу перед этапом 2 — какие поля в карточке клиента обязательны, публиковать
ли отзывы сразу или после проверки, лист ожидания — автоматически предлагать окно или через администратора.

## 4. Как продолжить с другого аккаунта

1. Убедиться, что у рабочего аккаунта Claude есть доступ к репозиторию `amanataichat-debug/voise-sistemSAAS`
   (GitHub подключён в claude.ai, приложение Claude установлено на репозиторий).
2. Открыть новую сессию Claude Code на этом репозитории, ветка **`2511-beauty`**.
3. Первое сообщение, например:
   > Прочитай docs/voksy_beauty_handoff.md, CLAUDE.md (абзац Voksy Beauty) и docs/voksy_beauty_plan.md.
   > Работаем в ветке 2511-beauty. Начинаем этап 2 «Клиенты возвращаются» — сначала задай мне вопросы
   > из раздела «Следующий шаг», потом делай.
4. Для тестов на базе в новой среде: поставить зависимости (`pip install -r requirements.txt`), поднять
   PostgreSQL, создать пустую базу и запустить `CHECK_DATABASE_URL=postgresql://… bash scripts/check_all.sh`
   (тестовая база очищается).
5. Коммиты — только в `2511-beauty`, без pull request, пока владелец не попросит.
