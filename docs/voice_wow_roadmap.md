# Дорожная карта «вау» голосового агента (ветка 1710-voice-fix-2test)

Источник фактов — `docs/openai_gpt_live_audio_reference.md` (справочник OpenAI, снят 17.10.2026).
Цель — живой, быстрый телефонный агент на `gpt-live-1`, чистый русский и понятный кыргызский.

## Что уже сделано (ветки 1710-voice-fix → 1710-voice-fix-2test)

- Знания агента целиком в промпте (лимит голосового слоя 6000 → 16000, бюджет знаний 9000,
  описания каталога до 25 позиций) — агент называет номера/цены сразу, без похода за функцией.
- Автозавершение звонка: прощание + тишина клиента 4 с → кладём трубку (тишину считаем только
  по клиенту, т.к. поток GPT-Live непрерывный).
- Пейсинг входящего аудио (token bucket, потолок 4 с) — убрал input_audio_rate_limit_exceeded.
- Живой стиль + язык в промпте (манера, чёткая речь, простой кыргызский без книжных слов).
- Бэкенд-модель делегирования gpt-5.6-terra → gpt-5.6-luna (быстрее).
- **Пакет скорости бэкенда** (этот коммит): `service_tier=priority` (Fast mode),
  `reasoning.effort=low`, `text.verbosity=low`, опц. `max_output_tokens` — через env
  `LIVE_DELEGATION_*`, пусто = не передавать.

## Ограничения (важно для обещаний клиентам)

- Русский и кыргызский для GPT-Live в документации OpenAI НЕ упомянуты. Качество RU/KY знаем
  только по своим тестам — обещать клиентам можно лишь то, что сами слышим на звонках.
- Голосов/акцентов для RU/KY нет; кастомные голоса — только «английские акценты».
- VAD/порогов тишины/эмоций/скорости как параметров в GPT-Live нет — только промпт + наш код моста.

## Правило работы

Одна правка — тестовый звонок (RU + KY) — лог. По логу смотрим строку
`задержка ответа: средняя … максимальная …` и журнал на ошибки (`responses_validation_failed`).
