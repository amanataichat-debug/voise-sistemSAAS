# Дорожная карта Voksy AI — голос + продажник (мастер-документ)

**Ветка:** `1910-voice-fix-test1` · **Деплой:** Render с этой ветки · **Обновлено:** 2026-10-19

Это ГЛАВНЫЙ план развития. Объединяет две линии:
1. **Голос** (телефонный агент на `gpt-live-1` + бэкенд `gpt-6-luna`) — из `voice_wow_roadmap.md` и справочника OpenAI `openai_gpt_live_audio_reference.md`.
2. **Продажник** (поведение Анри: квалификация, дожим, задачи, передача владельцу, память) — из системного промпта (`agent_prompts.py`) и живых тестов.

**Железное правило:** одна правка → один тестовый звонок (RU + KY) → лог → вывод. Не валим несколько изменений разом. Каждая правка — отдельный коммит с «что меняем и чего ждём», чтобы легко откатить.

**Эталон цели:** телефонный агент общается как живой менеджер — энергично, по делу, помнит клиента между каналами, сам ведёт к продаже/записи; русский чёткий, кыргызский понятный без акцента.

## 🧠 Этап 3. Память клиента (межканальная) — следующий крупный

**Проблема (тест 19.10):** клиент консультировался в WhatsApp, потом позвонил по телефону — агент его не помнит, начинает диалог с нуля («кто вы, чем занимаетесь»). Договаривались, что агент помнит клиента по имени/номеру и продолжает диалог.

Две части:
- **3a. Узнавание на входящем звонке.** По номеру звонящего поднять карточку CRM + историю (переписка, прошлые звонки, `memory`) и вложить сжато в `session.input` голосовой модели → «я вас помню, вы писали про кондитерскую». В 1810 уже есть распознавание клиента на входящем с незнакомого номера — опора для этого.
- **3b. Единая история между каналами.** WhatsApp / Telegram / Instagram / звонок пишут в одну историю контакта; звонок читает переписку, переписка читает итоги звонка. Ключ связки — номер телефона (+ имя как запасной).

Эффект: «вау, меня помнят», меньше походов в бэкенд, выше конверсия. Усилие: среднее. Риск: низкий.

## 🎭 Этап 4. Живость речи — эмоции, смех, интонации (RU + KY)

**Запрос владельца:** на русском агент иногда показывает эмоции/смех — нужно таких моментов больше, и на русском, и на кыргызском: лёгкий смех, «хм», живые интонации, человеческая подача.

- Правка промпта голосового слоя (`VOICE_AGENT_PROMPT_BASE` / подсказки `live_client.py`): разрешить и поощрять лёгкие эмоции, смешки, естественные паузы — но не переигрывать.
- В GPT-Live нет параметров эмоций/темпа — только промпт (подтверждено справочником). Поэтому ищем формулировки, слушаем на звонке.
- Отдельно подобрать формулировки под кыргызский, чтобы интонации были живыми и там.

Усилие: малое. Риск: низкий. Правило: одна формулировка → звонок → слушаем.

## 🗣 Этап 5. Кыргызский язык — понимание и подача

**Проблема:** `gpt-live-1` местами плохо РАСПОЗНАЁТ кыргызскую речь клиента (путает слова — видно в логах). Это ограничение модели (в документации OpenAI кыргызский для Live вообще не заявлен).

Варианты (от дешёвого к дорогому):
- 5a. Промпт-подсказки произношения и языка (быстро, частично).
- 5b. Тест отдельного пути для кыргызских звонков: каскад ElevenLabs + Yandex/Google STT под кыргызский (у нас уже есть `yandex_stt_client.py` / `google_stt_client.py`). Большое усилие, но реально поднимает понимание KY.

Усилие: 5a малое / 5b высокое. Риск: средний.

## Порядок работы (предложение)

1. **B1 + B2** (звонки: не долбить + окно) — критично для владельца, бьёт по доверию клиентов. Чиним вместе как «поведение дозвона», один тест.
2. **B3** (handoff → задача в платформе) — чтобы владелец видел задачи.
3. **Этап 3** (память клиента) — крупный, но самый «вау».
4. **Этап 4** (эмоции RU+KY) — быстро, приятно.
5. Дальше — 5/6 по ситуации.

На каждом шаге: правка → деплой в `1910-voice-fix-test1` → твой тестовый звонок → лог → вывод.
