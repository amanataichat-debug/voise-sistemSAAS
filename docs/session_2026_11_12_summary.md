## С чего начать новую сессию

1. Прочитать раздел «Чистая система» в `CLAUDE.md` и этот файл.
2. Поставить зависимости и запустить проверку одной командой:
   ```bash
   pip install -r requirements.txt pyflakes
   bash scripts/check_all.sh
   ```
   С тестовой PostgreSQL (база будет изменена) — полная проверка, включая сквозные цепочки и обход кабинета:
   ```bash
   CHECK_DATABASE_URL=postgresql://postgres:pg@localhost/voksy_test bash scripts/check_all.sh
   ```
   Последний результат: 929 проверок без базы + тесты на PostgreSQL + 1 123 запроса к кабинету — всё прошло.
3. Проверка перед коммитом (один раз в клоне): `git config core.hooksPath .githooks`.

## Промпты (решение: структуру не менять)

Замер (агент Анри, 30 пар вопрос-ответ, каталог 25 позиций): сообщение клиента ≈12–14 тыс. токенов на шаг
(промпт + инструменты кэшируются провайдером), звонок ≈5–6 тыс. токенов (лимит GPT-Live 16 тыс.).
Знания: частое (вопрос-ответ, секции, прайс) — в промпте, остальное — поиск (Postgres + Pinecone).

Три слоя (см. `CLAUDE.md`): код = механика; общий промпт платформы (`agent_prompts.py`, `voice_rules.py`);
владелец пишет только два поля — инструкция для переписки и для звонков. Новые короткие шаблоны Анри:
`docs/orchestrator_prompt_anri.md`, `docs/voice_agent_prompt_anri.md` — владельцу нужно вставить их в кабинете.
