Баштоодон мурунку суроолор

Сүйлөшүүнүн бир мүнөтү канча турат?
Жазылуу функцияларды ачат. Сүйлөшүү мүнөттөрү капчыгыңыздан сом менен, секунда боюнча эсептелет: үндүн мүнөтүнө 5,47 сом. Кирүүчү чалуулар ошончо турат, оператор аларды эсептебейт. O! номерлерине чыгуучу чалууга оператордун мүнөтү үчүн 1 сом кошулат, жалпысынан 6,47 сом. Start тарифин биринчи төлөгөндөн кийин капчыкка 150 сом кошобуз. Капчык кабинетте толукталат.
Агент кардарга биринчи өзү жаза алабы?
Ооба. Агент кардарды телефон номери боюнча таап, WhatsApp же Telegram аркылуу жазат. Profi тарифинде ал өзү да чалат, Start тарифинде жазат гана. Спам болбош үчүн жаңы чаттарга күнүмдүк лимиттер бар, ал эми сиз өзүңүз кат алышууга кошулганда, агент сиз тандаган убакытка унчукпай калат.
Агент коммерциялык сунушту кантип даярдайт?
Сиз логотипти, түстү жана байланыштарды бир жолу жүктөйсүз. Андан ары агент так ошол кардар үчүн PDF түзөт: каталогдон баалар жана сүрөттөр, керектүү шарттар. Start тарифинде документ кардар кайрылганда гана түзүлөт, Profi тарифинде агент муну өзү да жасай алат.
Кандай номерлерди туташтырса болот?
Кыргызстандын номерлерин (+996). Номерди биз туташтырабыз, кабинетте ал ассистентке байланыштырылат. Чыгуучу чалуулар азыр O! оператордун номерлерине гана жеткиликтүү.
Башка сервистерди туташтыруу же ачкычтар үчүн төлөө керекпи?
Жок. Үн, телефония жана жасалма интеллект мурунтан эле туташтырылган, эч нерсе жөндөөнүн кереги жок. Жазылууга жана капчыктан сүйлөшүү мүнөттөрүнө гана төлөйсүз.
Сыноо мезгилине эмнелер кирет?
Start тарифинин мүмкүнчүлүктөрү менен үч күн: ассистент, виджет, мессенджерлердеги агент, CRM, кирүүчү чалуулар жана билим базасы. Жазылууга төлөм талап кылынбайт, сүйлөшүү мүнөттөрү капчыктан төлөнөт. Автономдуу агент (өзү биринчи чалат) төлөнгөн Profi тарифинде гана.
Агент кардарларды кантип эстейт?
Ар бир байланыштын карточкасы бар: сүйлөшүүлөрдүн тарыхы, негизги фактылар жана эскертмелер. Агент аны ар бир сүйлөшүүдөн кийин жаңылап, кийинкисинин алдында окуйт, ошондуктан кардарды биринчи сөзгө чейин тааныйт.
Тарифти кантип төлөйм?
Сом менен, түз эле кабинетте, Finik төлөм сервиси аркылуу. Төлөгөндөн кийин тариф дароо күйгүзүлөт.
