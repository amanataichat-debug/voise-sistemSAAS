## 0. Контекст проекта

Это клон SaaS-платформы голосовых ИИ-ассистентов (оригинал — Voksy AI), разворачиваемый
для партнёра в Кыргызстане под брендом **Voksy AI**.

- Лендинг: React + Vite, исходники в `frontend/src/`, собирается в `backend/static/landing/`.
- ЛК (личный кабинет): ~20 самостоятельных vanilla HTML/CSS/JS страниц в `backend/static/`.
- Бэкенд: FastAPI, отдаёт всё как статику. **Бэкенд в этом ТЗ не трогаем вообще.**

### ⚠️ Правило сборки лендинга (из CLAUDE.md, обязательно!)

Render собирает только Python. После ЛЮБОЙ правки в `frontend/src/**`:

```bash
cd frontend && npm ci && npm run build
cd .. && git add -A backend/static/landing frontend
```

В коммите обязаны быть: удалённый старый `index-<hash>.js`, новый `index-<hash>.js`,
обновлённый `index.html`. Если в `git status` нет изменений в `backend/static/landing/` —
сборка не выполнена, прод останется старым.

## 3. Дизайн-система «White Depth Grid / Black Accent»

Белая тема с ощущением глубины и инженерной сетки, акцент — **глубокий чёрный**
(монохромный, «премиальный» стиль: чёрные кнопки и активные состояния на белом,
цвет используется только для статусов и одного редкого тёплого штриха). Все токены — в
`frontend/src/styles/variables.css` (лендинг) и в новом общем файле
`backend/static/css/voicesystem-theme.css` (ЛК).

### 3.1 Палитра

```css
:root {
  /* Поверхности — белый с层ами глубины */
  --vs-bg: #FAFBFD;             /* фон страницы, чуть холодный */
  --vs-surface: #FFFFFF;        /* карточки */
  --vs-surface-raised: #FFFFFF; /* карточки над карточками (отличаются тенью) */
  --vs-ink: #0E1526;            /* основной текст, почти чёрный с синевой */
  --vs-ink-soft: #4A5568;       /* вторичный текст */
  --vs-ink-faint: #8A94A6;      /* подписи, плейсхолдеры */

  /* Акцент — глубокий чёрный (монохром) */
  --vs-accent: #0A0C10;         /* кнопки, активные состояния, ссылки-underline */
  --vs-accent-hover: #1C2028;   /* hover чёрных элементов — чуть светлее, не синее */
  --vs-accent-soft: #F1F3F6;    /* заливки чипов, hover-фоны, активный пункт сайдбара */
  --vs-on-accent: #FFFFFF;      /* текст/иконки на чёрном */
  --vs-warm: #F59E0B;           /* единственный цветной штрих: бейджи «рекомендуем», редкие подчёркивания */

  --vs-success: #16A34A;
  --vs-error: #DC2626;

  /* Сетка и линии */
  --vs-line: #E6E8EC;
  --vs-grid-line: rgba(10, 12, 16, 0.05);
}
```

Правила монохрома: чёрный — единственный акцент. Кнопка-CTA: чёрная с белым
текстом, hover — `--vs-accent-hover` + подъём. Вторичная кнопка: белая с чёрной
рамкой 1px, hover — инверсия (чёрный фон, белый текст, transition 200ms — очень
эффектно). Ссылки: чёрные с подчёркиванием, hover — подчёркивание утолщается.
Не вводить других цветов, кроме `--vs-warm` (точечно) и статусных success/error.

### 3.2 Глубина (elevation) — 4 уровня теней

Тени мягкие, двухслойные (ключевая + ambient), никакого чистого чёрного:

```css
--vs-shadow-1: 0 1px 2px rgba(10,12,16,.05), 0 1px 3px rgba(10,12,16,.06);
--vs-shadow-2: 0 4px 12px rgba(10,12,16,.07), 0 1px 3px rgba(10,12,16,.05);
--vs-shadow-3: 0 12px 32px rgba(10,12,16,.12), 0 2px 8px rgba(10,12,16,.06);
--vs-shadow-4: 0 24px 64px rgba(10,12,16,.18), 0 4px 16px rgba(10,12,16,.08);
```

Правила: страница `shadow-0`, карточки `shadow-1`, hover-карточки `shadow-2→3`,
модалки/дропдауны `shadow-4`. Глубину дополняют границы `1px solid var(--vs-line)`.

### 3.3 Фоновая сетка

Инженерная сетка на фоне ключевых секций (hero, тарифы) и body ЛК:

```css
.vs-grid-bg {
  background-image:
    linear-gradient(var(--vs-grid-line) 1px, transparent 1px),
    linear-gradient(90deg, var(--vs-grid-line) 1px, transparent 1px);
  background-size: 32px 32px;
}
/* + радиальная маска, чтобы сетка растворялась к краям: */
.vs-grid-fade { -webkit-mask-image: radial-gradient(ellipse 80% 60% at 50% 40%, #000 40%, transparent 100%); }
```

Поверх сетки в hero — 2–3 больших размытых пятна (`filter: blur(120px)`) для
«дыхания». В монохроме чёрные пятна выглядят грязью, поэтому: одно тёплое
(`--vs-warm`, opacity .10) и одно-два графитовых (`#0A0C10`, opacity .04–.06) —
едва заметные, дающие объём, а не цвет.

### 3.4 Типографика

- Шрифт: **Inter** (или Manrope) — обязательно проверить кыргызские глифы
  **Ң ң, Ө ө, Ү ү** (Inter поддерживает). Подключать через `@font-face` с
  self-hosted woff2 или существующий механизм проекта — НЕ добавлять внешние CDN,
  если страницы уже работают офлайн-шрифтами.
- Шкала: 56/40/28/20/16/14 px, заголовки `letter-spacing: -0.02em`, `font-weight: 700`.
- Радиусы: 10px (кнопки, инпуты), 16px (карточки), 24px (hero-панели).

## 6. Анимации — «душа и живость»

### 6.1 Технические правила (обязательны)

- Анимировать только `transform` и `opacity` (60fps, без reflow). Никаких
  анимаций `width/height/top/left/box-shadow` в keyframes (тень менять можно
  через transition на hover — это редкое событие).
- Все анимации обёрнуты в `@media (prefers-reduced-motion: no-preference)`.
  При `reduce` — всё статично, контент виден сразу.
- Изинги: появление `cubic-bezier(0.16, 1, 0.3, 1)` (easeOutExpo-подобный),
  микро-hover `cubic-bezier(0.34, 1.56, 0.64, 1)` (лёгкий overshoot).
- Длительности: hover 150–200ms, появления 500–700ms, декоративные циклы 6–20s.
- Scroll-появления — через `IntersectionObserver` (порог 0.15, `once: true`),
  утилита-класс `.vs-reveal` + `.is-visible`. На лендинге сделать маленький
  компонент/хук `useReveal()`; в ЛК — 15 строк vanilla JS в теме (отдельный
  `voicesystem-motion.js`, подключается `defer`).

### 6.2 Каталог анимаций — лендинг

| Где | Что |
|---|---|
| Hero: заголовок | Появление каскадом: заголовок → подзаголовок → CTA, каждый `opacity 0→1` + `translateY(16px→0)`, задержки 0/120/240ms |
| Hero: blur-пятна | Медленный дрейф `translate/scale` циклом 18–24s, `will-change: transform` |
| Hero: сетка | Лёгкий параллакс: `background-position` сдвигается на 10–20px от scroll (через `transform` контейнера, не bg-position, если дешевле) |
| Navbar | Появление тени при скролле (transition 200ms); подчёркивание пунктов — линия растёт из центра (`scaleX 0→1`) |
| Переключатель KY/RU | «Пилюля» активного языка перемещается `transform` слайдом 200ms |
| Карточки (все секции) | Reveal по одному с шагом 80ms; hover: `translateY(-4px)` + тень `1→3` + иконка внутри `scale(1.06)` |
| Кнопка CTA | Hover: `translateY(-2px)` + тень; active: `scale(0.98)`; по клику — короткий ripple (псевдоэлемент, `scale 0→2.5` + fade 450ms) |
| Цифры/метрики (если есть) | Count-up от 0 при появлении в вьюпорте (rAF, 800ms, easeOut) |
| PricingSection | Рекомендованный тариф: бейдж мягко «дышит» `scale 1↔1.04` циклом 3s |
| Формы Auth | Ошибка — shake `translateX ±6px` 300ms; успех — галочка рисуется `stroke-dashoffset` 400ms; фокус инпута — рамка `--vs-accent` + мягкое свечение `box-shadow: 0 0 0 4px var(--vs-accent-soft)` |
| InlineNotification | Вход `translateY(-8px→0)+opacity`, выход — reverse |
| ScrollProgress | Оставить, перекрасить в `--vs-accent` |
| Footer | Ссылки: hover — `translateX(3px)` со стрелкой-псевдоэлементом |

### 6.3 Каталог анимаций — ЛК (сдержаннее, это рабочий инструмент)

| Где | Что |
|---|---|
| Сайдбар: пункты | Hover: фон-заливка 150ms + иконка `translateX(2px)`; активная полоска — `scaleY 0→1` 200ms при переключении |
| Карточки/статы дашборда | Reveal при загрузке страницы каскадом (шаг 60ms, только первый экран) |
| Кнопки | Как на лендинге (hover-lift + active-press), без ripple |
| Таблицы | Hover строки — фон 120ms; новая строка — fade-in |
| Модалки | Открытие: overlay fade 200ms + окно `scale(0.96→1)+opacity` 250ms |
